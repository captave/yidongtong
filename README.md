# 易懂通 Android

## v1.3.4：暖色界面与爱心关怀图标

版本：**v1.3.4**（versionCode：8） · 更新日期：2026-11-01 · Android 8.0及以上。

最新版本采用暖杏色背景、白色卡片与陶橙强调色，深色主题使用暖棕配色。启动图标为暖色底的爱心、信息气泡与声波组合。已覆盖安装到测试设备并检查启动和页面显示，保留原有数据与设置。

## 项目背景

老年用户面对小字短信、验证码、陌生网址及资金操作提醒时，可能难以阅读和判断。易懂通以大字阅读、点击普通话朗读、本地风险规则和可选的 AI 辅助分析，帮助用户理解信息，并在主动开启后通知可信任的家人。

项目当前为本地安装测试应用，风险提示不等于已确认诈骗。严格规则会将正常业务验证码、官网链接及包含转账的反诈提醒也标记危险，用户可在规则库自行选择。

## 严格规则库

在“安全守护 → 安全规则库”可选择12类危险、12类可疑规则，查看24类生活场景示例，并输入短信本地试判。默认全部开启，设置只影响后续收到的信息。

严格规则将验证码（不限长度）、取件/提货等领取凭证、“链接”字样、网址及转账标记危险，包括正常业务通知或反诈提醒。界面显示命中规则，不代表已确认诈骗。普通长订单号不单独触发。

DeepSeek 只能提高本地等级；“通知家人”开启后同步本地或AI判断为可疑/危险的新短信，关闭则不发送。试判不联网、不发送；应用通知不自动转发。摘要隐藏验证码、口令、网址与长号码。数据库与90天保留策略维持原有实现。

面向老年用户的本地短信语音与安全提醒应用。


易懂通帮助老年用户以大字阅读、普通话朗读的方式理解手机信息，并通过本地规则和可选的 DeepSeek 分析识别风险。遇到危险信息时，可联系家人，或在用户授权后自动发送提醒短信。

完整版本历史见 [更新日志](CHANGELOG.md)。

每位用户可以在 App 内填写自己的 DeepSeek API Key，Key 使用 Android Keystore 保护的 AES-GCM 密钥加密后保存在应用私有空间，不写入源码或 Git。

## 已实现

- 收到短信或已授权应用通知后显示高优先级提醒，并提供“朗读内容”按钮。
- 用户开启的本地规则立即识别风险；验证码不限长度，取件码、链接与转账严格标记危险，AI 不得降低本地等级。
- 可由用户明确开启或关闭 DeepSeek 云端分析；关闭时不会上传新消息，开启后使用用户自己的 API Key 直接请求 DeepSeek，判断为安全、可疑或危险。
- 用户开启“通知家人”并授予发短信权限后，本地或AI判定为可疑、危险的新短信会向紧急联系人发送脱敏摘要；关闭则不发送，应用通知不自动转发。
- 自动短信使用系统的发送结果回执记录“正在发送 / 已发送 / 发送失败”，不会仅因调用了 `SmsManager` 就显示发送成功。
- 风险信息可从通知或应用内打开系统拨号器联系紧急联系人。
- 大字号、高对比度、单列布局、大尺寸按钮，并支持浅色/深色主题和普通话语速调节。
- 信息记录保存在应用私有 SQLite 数据库中，只保留近 90 天；支持按号码、正文、判断理由查询，支持删除单条或清空全部。
- DeepSeek API Key 由用户在 App 内自行配置，经 Android Keystore 加密后保存在本机，不写入源码或日志。
- 语音服务只选择不需要网络的普通话声音；未安装离线普通话语音包时拒绝朗读并提示安装。
- 锁屏通知隐藏短信正文，解锁后才显示内容。

云端分析和危险信息短信同步是两个独立开关，均默认关闭。未配置 API Key 时，本地验证码规则和原有提醒仍可正常工作。

## 技术栈与处理流程

- Kotlin + Android 原生 XML/View，大字号分组界面；SharedPreferences 保存主题、语速与开关。
- Android TextToSpeech 提供离线普通话朗读。
- BroadcastReceiver 接收短信，NotificationListenerService 读取已授权的应用通知。
- HTTPS + DeepSeek Chat API + 严格 JSON 校验，实现辅助风险判断；Android Keystore + AES-GCM 保护用户 Key。
- SQLiteOpenHelper 管理本地记录，WorkManager 执行后台分析、重试及每日过期清理。
- SmsManager 发送高危短信提醒，PendingIntent + BroadcastReceiver 记录系统发送结果。
- Gradle 构建；JUnit 与 AndroidX Test 验证核心逻辑和真机行为。

处理流程：接收信息 → 本地初筛并入库 → 按开关调用 DeepSeek → 更新风险提醒 → 按同步开关通知紧急联系人。

记录保留期按 90 天计算。清理由系统调度，并在数据库访问时再次执行；短信“已发送”表示系统确认发送成功，不代表联系人已阅读。

## 用 Android Studio 运行

1. 在 Android Studio 中打开 `D:\易懂通-Android`。
2. 等待 Gradle Sync 完成。
3. 连接开启 USB 调试的 Android 手机。
4. 点击 Run 安装。
5. 首次启动后点击“开启短信守护”，授予短信和通知权限。
6. 填写并保存一位可信任的紧急联系人。
7. 如需智能判断，在“安全守护”中填写并保存自己的 DeepSeek API Key，然后开启 DeepSeek 分析。
8. 如需同步危险信息，再开启“危险信息自动短信通知联系人”并授予发短信权限。

应用不读取通讯录，也不申请直接拨号权限。点击紧急联系人按钮只打开系统拨号器，仍需用户确认拨出。仅在用户保存自己的 API Key、阅读确认说明并开启云端分析后，后续收到的短信以及“通知使用权”读取到的通知正文才会直接发送到 DeepSeek。

## 可选后台代理参考

`backend` 目录仍保留零第三方依赖的 Node.js 20 后台代理参考，但当前 Android 版本不使用它。若未来改回统一后台，真实 DeepSeek Key 只应设置在服务器环境变量中：

```powershell
$env:DEEPSEEK_API_KEY = '在服务器上填写真实 Key'
$env:YIDONGTONG_PROXY_TOKEN = '一段足够长的随机访问令牌'
$env:PORT = '8787'
node .\backend\server.mjs
```

正式环境必须通过 HTTPS 反向代理或云函数对外提供服务，并增加用户/设备身份、短期可撤销令牌、设备证明、主体限流和监控。

## 命令行验证

工程所在上级目录包含中文字符。在部分 Windows/Gradle 组合中，单元测试工作进程无法解析中文类路径。测试时可把构建输出临时放到纯英文目录：

```powershell
$env:JAVA_HOME = 'D:\Android Studio\jbr'
$env:GRADLE_USER_HOME = 'D:\Android\GradleHome'
$env:YIDONGTONG_BUILD_DIR = 'D:\Android\builds\yidongtong'
.\gradlew.bat testDebugUnitTest lintDebug
```

正常 APK 构建不需要设置 `YIDONGTONG_BUILD_DIR`：

```powershell
$env:JAVA_HOME = 'D:\Android Studio\jbr'
$env:GRADLE_USER_HOME = 'D:\Android\GradleHome'
$env:YIDONGTONG_BUILD_DIR = 'D:\Android\builds\yidongtong'
.\gradlew.bat assembleDebug
```

Debug APK 输出位置：`D:\Android\builds\yidongtong\outputs\apk\debug\app-debug.apk`。

## 使用限制

- 用户在系统设置中强行停止应用后，Android 会暂停向应用投递短信广播，重新打开一次应用即可恢复。
- 不同手机厂商可能允许用户关闭通知弹窗，请在系统通知设置中保持“短信提醒”渠道开启。
- 手机系统可能保留通知历史，这部分记录由系统通知设置管理，不由易懂通保存。
- DeepSeek 是第三方云端服务，分析准确率不能达到 100%，高风险操作仍应联系家人、银行或警方核实。
- 当前仓库和 APK 均不包含预置 DeepSeek API Key；用户未在本机保存有效 Key 时，App 会阻止开启 DeepSeek。
- 本机加密可以避免明文落盘，但无法防御已经完全控制手机、解锁系统或动态注入应用进程的高级攻击者，适合当前本地安装测试。
- 自动同步要求设备具备 SIM 卡和短信能力；仅有 Wi-Fi 的平板不能实际发送短信。
- 该版本使用 `RECEIVE_SMS` 和 `SEND_SMS` 权限，适合本地安装测试。发布 Google Play 前必须重新评估短信权限政策。
